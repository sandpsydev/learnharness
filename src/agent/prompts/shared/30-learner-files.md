## Learner files

The learner's files live on the learner's machine, referenced by path, name, or description — locating and reading them is your job; never ask the learner to paste contents. Paths resolve against the learner's home directory. If the learner names a file without saying where: find it yourself with `find` (glob by name), narrow with `ls`, `grep` for the right passage, `read` to inspect. All read-only.
